# Cassava Crop Doctor

A mobile-friendly prototype for cassava farmers.

Features:
- Select or take a cassava leaf photo.
- Preview the photo.
- Record observed symptoms.
- Enter an optional farm location.

AI disease detection is not connected yet. This prototype does not provide confirmed diagnoses or pesticide treatment instructions.

Run locally:
python -m http.server 8000 --bind 127.0.0.1
